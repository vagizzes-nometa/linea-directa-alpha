# Línea Directa · Alpha

Juego de parkour speed: de la plaza al mundo. Versión de prueba (Alpha 0.65).

**Jugar:** https://vagizzes-nometa.github.io/linea-directa-alpha/

En iPhone: abrilo en Safari → Compartir → "Agregar a pantalla de inicio". Después funciona sin conexión.

Este repo tiene solo el juego compilado. El código está en un repo privado.

## Créditos de gráficos
- Kenney (www.kenney.nl): Tiny Town, RPG Urban Pack, Roguelike Indoor, Roguelike Modern City y Pixel UI. CC0.
- LimeZu (limezu.itch.io): "Modern Interiors" versión gratis, uso no comercial, y "Serene Village revamped", CC BY 4.0.
